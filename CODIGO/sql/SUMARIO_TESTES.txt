⚠️ TROUBLESHOOTING:
════════════════════════════════════════════════════════════════════════════════

Erro: "Database doesn't exist"
  → Certifique-se que 01_tabelas.sql foi executado primeiro

Erro: "Access denied for user"
  → Use credenciais corretas: MYSQL_USER="seu_user" MYSQL_PASS="sua_pass"

Erro: "MySQL server not running"
  → Inicie o MySQL:
    Linux: sudo systemctl start mysql
    macOS: brew services start mysql
    Windows: Services (services.msc)

Erro: "Foreign key constraint fails"
  → Verifique a ordem: 01_tabelas.sql → 03_povoamento.sql → testes
