Catalogo de funcoes (mydb_uniforme)

1. fn_custo_total_equipamento
Devolve o custo total acumulado de um equipamento somando todos os registos de manutencao.custo.

Assinatura sugerida:
fn_custo_total_equipamento(p_equipamento_id INT) RETURNS DECIMAL(10,2)

2. fn_calcular_dias_em_manutencao
Recebe manutencao_id e devolve os dias decorridos entre data_inicio e data_fim; se data_fim for NULL usa CURDATE().

Assinatura sugerida:
fn_calcular_dias_em_manutencao(p_manutencao_id INT) RETURNS INT

3. fn_total_horas_investidas
Recebe manutencao_id e devolve a soma de horas_trabalho dos tecnicos nessa manutencao.

Assinatura sugerida:
fn_total_horas_investidas(p_manutencao_id INT) RETURNS INT

4. fn_custo_historico_equipamento
Recebe equipamento_id e devolve o custo historico total em manutencoes (equivalente a fn_custo_total_equipamento).

Assinatura sugerida:
fn_custo_historico_equipamento(p_equipamento_id INT) RETURNS DECIMAL(10,2)

5. fn_peca_na_garantia
Recebe peca_id e indica se a peca esta em garantia na data atual.

Assinatura sugerida:
fn_peca_na_garantia(p_peca_id INT) RETURNS BOOLEAN

6. fn_contar_ordens_ativas_tecnico
Recebe tecnico_id e devolve quantas ordens ligadas ao tecnico estao ativas (estado_atual <> 'Concluida').

Assinatura sugerida:
fn_contar_ordens_ativas_tecnico(p_tecnico_id INT) RETURNS INT
